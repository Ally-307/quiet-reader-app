# 备份恢复 v2

## 范围

Android 原生 v0.1.0 可通过 Storage Access Framework 导出或选择 ZIP。备份包含本地书籍、书源原始 JSON、阅读进度、排版设置，以及 WebDAV 地址和用户名；不包含密码或系统 TTS 数据。

## 格式

- 根目录必须只有 `manifest.json`、`books/` 文件和 `sources/` 文件。
- `manifest.json` 的 `format` 固定为 `quiet-reader-backup`，当前 `version` 为 `2`。
- 每个书籍和书源记录保存稳定标识、显示元数据、归档路径、原始字节数和 SHA-256。
- v1 备份仍可读取，但书籍标题、作者、进度和书源启用状态只能按旧格式可获得的信息降级恢复。

## 恢复流程

1. 将用户选择的 ZIP 复制到应用私有暂存区。
2. 校验文件大小、条目数量、路径、重复项、清单结构、逐项大小与 SHA-256。
3. 检查书源清单地址与原始 JSON 是否一致，并生成书籍、书源、设置冲突预览。
4. 用户选择“保留本地”时，仅合并无冲突内容；选择“使用备份”时覆盖冲突并恢复设置。
5. 文件先写入临时路径，再替换目标；元数据使用一次同步提交。运行时异常会恢复旧文件和旧设置。

## 限制

- ZIP 文件最大 512 MiB，单本书最大 256 MiB，单个书源最大 4 MiB。
- 解压后总数据最大 480 MiB，最多 256 本书、256 个书源和 513 个 ZIP 条目。
- 当前回滚覆盖同一进程内的异常；应用在文件替换瞬间被系统强制终止时，完整恢复日志要等 Room 迁移阶段补齐。
- 尚未提供“只恢复书籍 / 只恢复设置”等逐类选择。
