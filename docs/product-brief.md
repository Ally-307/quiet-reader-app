# 产品需求简报

## 1. 产品定位

一款面向重度阅读者的 Android 本地优先阅读器。用户可以导入自己的网络书源和本地书籍，在一个安静、可深度调整的界面中完成找书、阅读、听书、统计与跨设备恢复进度。

产品不提供未经授权的预装书源，不托管书籍正文，也不绕过目标网站的访问控制。书源内容及使用合规性由导入者负责。

## 2. 首版用户

- 已使用或了解阅读 3.0 / Legado 书源的用户
- 同时阅读网络小说和 EPUB、TXT、PDF 本地文件的用户
- 对字体、段距、页边距、翻页和主题有精细要求的用户
- 需要系统 TTS 听书和跨 Android 设备同步进度的用户

## 3. 首版范围

### 3.1 书架

- 网格和列表两种视图
- 最近阅读、未读更新、本地书籍和自定义分组
- 置顶、归档、批量管理、阅读进度展示
- 导入 EPUB、TXT、PDF
- 书籍详情、目录、缓存状态与来源信息

### 3.2 自定义书源

- 导入单个或批量 Legado 兼容 JSON 书源
- 启用、禁用、分组、排序、导出与删除
- 搜索、详情、目录和正文规则测试
- 显示请求日志、解析结果和错误位置
- 不内置第三方书源仓库

### 3.3 阅读与字体排版

- 字体文件导入与字体切换
- 字号、字重、行距、段距、页边距、首行缩进
- 左右翻页、上下滚动和覆盖翻页
- 日间、夜间、护眼与用户自建主题
- 亮度、常亮、横竖屏与音量键翻页
- 目录、书签、搜索、笔记与进度跳转的基础入口

### 3.4 听书

- 调用 Android 已安装的 TTS 引擎
- 语音、语速、音调和定时停止
- 段落高亮与锁屏媒体控制
- 后台播放、耳机控制与章节连续播放

### 3.5 统计排行榜

- 今日、本周、本月阅读时长
- 连续阅读天数、完成书籍数、阅读字数估算
- 书籍阅读时长排行和完成度排行
- 所有统计默认仅保存在本地，可随 WebDAV 同步

首版的“排行榜”是个人阅读榜，不包含公开社交榜、好友关系或公共账号体系。

### 3.6 多设备同步

- 本地优先，不登录也能完整使用
- WebDAV 同步书架元数据、阅读进度、书签、笔记、主题、书源配置和统计
- 敏感字段加密后上传；WebDAV 密码使用 Android Keystore 本地保护
- 冲突记录可查看，进度按时间戳合并，笔记按记录级合并
- 书籍正文默认不上传，用户可单独开启本地书籍同步

## 4. 主要导航

底部四栏：

1. 书架
2. 发现
3. 统计
4. 我的

“发现”承载跨书源搜索、书源管理与规则调试；阅读器从书架、搜索结果或历史记录进入。听书作为阅读器内的持续播放能力，并在底部显示迷你播放器。

## 5. 关键流程

### 首次使用

欢迎页 → 选择导入本地书籍或书源 → 权限按需请求 → 进入书架。

### 导入书源

发现 → 书源管理 → 导入 JSON / 扫码 / 粘贴 → 安全预览 → 选择启用项 → 测试 → 完成。

### 阅读

书架 → 书籍 → 阅读器 → 点击中央打开控制层 → 调整排版或启动听书 → 自动保存进度。

### 同步

我的 → 同步 → 配置 WebDAV → 连接测试 → 选择同步项目 → 首次合并预览 → 开启自动同步。

## 6. 非目标

- 首版不做 iOS、桌面端或网页阅读器
- 首版不做公开书源市场
- 首版不做公共社交排行榜、评论区和好友系统
- 首版不做付费订阅、广告或内容分发
- 首版不保证完整兼容 MOBI、AZW3、CBZ

## 7. 成功标准

- 用户可在离线状态导入并阅读 EPUB、TXT、PDF
- 用户可导入 Legado JSON，定位并测试书源规则错误
- 排版修改即时生效且能保存为主题
- TTS 可后台连续朗读并由系统媒体控件控制
- 两台设备可通过 WebDAV恢复书架元数据、阅读进度和设置
- 书源故障不会导致应用崩溃，错误可定位、可禁用、可恢复
