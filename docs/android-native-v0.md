# Android 原生 v0.1.0

## 目标

将已确认的 Web v0 交互和视觉规则迁移到 Kotlin + Jetpack Compose，先验证 Android 原生的导航、阅读入口、面板层级和动效节奏，再接入真实数据能力。

## 已实现

- 书架首屏：0 本空状态、本地书籍导入，以及导入后的开始阅读 / 继续阅读入口
- 四栏导航：书架、发现、统计、我的
- 发现页：找书 / 我的书源切换、搜索输入、规则集列表和书源导入入口
- 阅读器：正文、控制层、书签入口、目录入口、排版面板和听书面板
- PDF 阅读：Android 原生 `PdfRenderer`、串行页面渲染、可见页懒加载、页面缓存、适合宽度 / 显示整页模式、当前页 / 总页数进度
- 统计页：周期筛选、阅读时长、连续阅读、完成书籍与排行榜空状态，所有未采集指标从 0 开始
- 我的页：排版、听书、主题、WebDAV 同步和备份入口
- 备份恢复：SAF 导出/选择 ZIP、v2 清单与 SHA-256、冲突预览、合并或覆盖策略、异常回滚
- 动效：页面 280ms 淡入/位移、控制层 220ms 淡入、底部面板使用 Material 过渡
- 视觉：纸张底色、墨色文字、低饱和强调色、窄圆角、衬线正文与无衬线界面文字

## 当前边界

首次安装不预置演示书籍或统计样例，书架只显示用户真实导入的数据。以下能力尚未接入：

- PDF 文字提取与基于文字的 TTS（当前 PDF 固定版式阅读已接入；EPUB 已支持基础 XHTML/HTML 正文提取）
- Legado JSON 的规则执行和调试日志（当前完成结构校验、名称/地址提取、启停和原始 JSON 保存）
- Room / DataStore 的持久化（v0 使用 SharedPreferences + 应用私有文件，后续可平滑迁移）
- 后台媒体服务和锁屏控制（前台系统 TTS 播放、暂停与语速已接入）
- WebDAV 加密同步、冲突合并和 Android Keystore

## 本轮增量

- 通过 Android Storage Access Framework 选择 EPUB、TXT、PDF 和 JSON
- TXT 导入后进入书架，支持章节识别、编码回退和正文阅读
- 书源 JSON 支持数组或单对象，导入前不发起网络请求
- “粘贴规则”支持直接粘贴 JSON 并在本地校验后保存
- 书源启停、排版字号/行距/字体选择、WebDAV 地址/用户名均可恢复
- 系统 TTS 可朗读当前正文片段，支持播放/暂停与语速调节
- “备份与恢复”已支持 ZIP 选择、完整性校验、冲突预览、保留本地或使用备份
- PDF 已支持固定版式连续阅读，页面按需渲染并可切换适合宽度 / 显示整页
- 移除全部演示书籍、样例正文、伪造时长与排行榜；统计在真实采集接入前保持 0
