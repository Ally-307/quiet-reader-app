# 可点击 v0 说明

## 目标

在开始 Android 原生工程之前，用一个可交互移动端原型确认信息架构、视觉温度和主要操作路径。v0 不连接真实书源、TTS、文件系统或 WebDAV。

## 已覆盖界面

1. 书架首页与继续阅读
2. 本地 EPUB、TXT、PDF 导入入口
3. 阅读正文与显隐控制层
4. 字号、行距、页边距、字体和主题调整
5. 听书控制与跨页面迷你播放器
6. 跨书源搜索入口、书源启停与导入
7. Legado 规则、测试结果和日志
8. 个人阅读统计与书籍时长排行
9. WebDAV 配置和同步项目选择

## 关键交互

- 点击书封或“继续阅读”进入阅读器。
- 点击正文切换阅读控制层。
- 阅读控制层可打开排版或听书抽屉。
- 开始听书后返回书架，底部出现持续迷你播放器。
- “发现”页可切换找书和书源；点击“我的规则集”进入调试页。
- 调试页运行完整测试后显示四项通过结果，可切换规则和日志。
- 统计页可切换本周、本月和今年。
- “我的”进入 WebDAV 多设备同步设置。
- 桌面和移动预览均可通过右下角 Tweaks 切换三种书架密度、纸张肌理和“动效预览”；开启动效预览会将 `?motion=on` 写入当前地址。

## 动效

- 底部导航与二级页面以 280ms 的淡入和 4px 轻位移切换；进入阅读器使用同样时长的 6px 横向过渡。
- 排版、听书和导入抽屉以 260ms 轻微上浮出现，并以 180ms 收起；遮罩同步淡入淡出。
- 阅读控制层只在显示时淡入，正文、书封网格和排版滑块保持静止，避免干扰长时间阅读。
- 系统开启“减少动态效果”时，默认所有动画即时结束，抽屉也不保留关闭等待；仅在用户显式开启“动效预览”时恢复上述时长，用于原型验收。

## 验证结果

- JavaScript 与服务脚本语法检查通过。
- 412 × 915 Android 视口无横向溢出。
- 当前核心页面可见按钮最小触控尺寸为 48px。
- 应用内浏览器在最新代码加载后无新的错误或警告；此前无效的 `book-search` 图标已替换。
- 已复验书架本地导入、书源导入、听书和排版抽屉的显示与关闭；系统“减少动态效果”开启时均即时结束。
- 已在移动视口开启“动效预览”，复验页面切换、阅读器进入、控制层显隐、抽屉出现与收起；计算时长分别为 280ms、220ms、260ms 和 180ms。
- 已检查书架、阅读器、排版抽屉、夜间主题、听书、书源调试、统计和同步设置。

## v0 确认结论

- 交互信息架构与视觉方向确认，可进入 Android 原生实现。
- v0 仍是本地可点击原型，不代表真实文件导入、书源网络请求、系统 TTS 或 WebDAV 已接通。

## v0 假设

- 排行榜是个人阅读数据排行，不是公开社交榜。
- 首版同步采用 WebDAV，本地优先且不强制注册账号。
- 书源由用户自行导入，不提供未经授权的内置来源。
- Android 原生实现采用 Kotlin、Jetpack Compose、Room、DataStore、WorkManager 和 Media3。
