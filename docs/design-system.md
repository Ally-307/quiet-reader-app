# 设计系统确认稿

## Design Read

- **Artifact**：Android 原生阅读器及其可点击移动端原型
- **Audience**：长期阅读、导入自定义书源、在意排版与数据归属的中文用户
- **Visual language**：MUJI / 原研哉式日系编辑极简，空白、纸张、细线与安静排版
- **Mode**：Greenfield
- **Visual variance**：4/10。导航遵循 Android 熟悉结构，在书架编排和阅读主题中保留辨识度。
- **Motion intensity**：2/10。仅使用状态反馈和短淡入，阅读时不制造视觉干扰。
- **Information density**：5/10。书架保持舒展，书源管理与调试页通过分组和渐进披露承载高密度信息。
- **Asset dependence**：3/10。界面主要由真实书封、排版和结构承担；原创封面只用于原型样例。
- **Brand fidelity**：3/10。新品牌，可建立独立视觉语言。

## 四项定位

- **叙事角色**：第一屏直接是可操作书架；阅读器是全屏沉浸面；统计页像一本克制的阅读年鉴；书源调试页是精确工具面。
- **观看距离**：约 25–40 厘米的手机屏幕，正文和触控元素优先保证长时间舒适与单手操作。
- **视觉温度**：安静、温暖、可信，不做可爱化装饰，不用强烈科技感。
- **容量检查**：书架首屏容纳继续阅读和 4–6 本书；高密度参数收进底部抽屉、分组列表和二级页面，正文页保持纯净。

## Design Decisions

- **Anchor / recipe**：`muji-kenya-hara`，只采用这一套视觉锚点；Android 平台规范仅负责交互可用性。
- **颜色**：
  - 纸张底色 `#F4F2EC`
  - 主墨色 `#2A2A28`
  - 次级文字 `#77756F`
  - 发丝分割线 `#D9D6CD`
  - 浮层白 `#FBFAF6`
  - 深夜背景 `#20201E`
  - 夜间正文 `#E7E2D8`
  - 唯一点色 `#B63A31`，只用于当前进度、录音式听书状态和重要错误，不用于大面积背景
- **字体**：
  - UI 与标题：`Noto Sans CJK SC` / Android 中文无衬线，400–500
  - 阅读正文：默认 `Noto Serif CJK SC` / 思源宋体风格，用户可导入字体
  - 数字与调试信息：等宽数字特性，必要时使用 Android 等宽字体
  - 不使用负字距；标题克制，正文行高默认 1.75
- **间距**：4pt 基础栅格，常用 8 / 12 / 16 / 24 / 32 / 48；阅读页左右边距默认 24dp，可调 12–48dp。
- **圆角**：主界面 0–4dp；书封维持 2dp；底部设置抽屉 8dp。只在需要表达可拖动浮层时出现较明显圆角。
- **阴影**：默认无阴影。层级由底色、1px 线和遮罩表达；底部抽屉仅有极淡顶部遮罩。
- **动效**：页面切换使用 280ms 淡入与轻位移，阅读器进入使用同样时长的短横向过渡；控制层显示为 220ms 淡入；底部抽屉以 260ms 轻上浮出现、180ms 收起；正文、书封网格和排版滑块保持静止；默认遵循系统“减少动态效果”，原型验收可显式开启“动效预览”。
- **图标**：使用 Material Symbols / Compose Material Icons 的熟悉符号，按钮触控区域不小于 48dp，陌生操作提供内容描述。

## 组件语法

- **书架**：不使用浮动卡片墙。书封直接排在纸张背景上，书名、作者和进度形成细小的编辑式题注。
- **继续阅读**：横向整幅信息带，不套嵌卡片；左侧书封，右侧标题、最近章节和一条细进度线。
- **底部导航**：四项等宽，图标为主、短标签为辅；选中项用墨色与细上划线，不使用彩色胶囊。
- **阅读器**：正文占据主画面；顶部与底部控制层按点击显隐。排版调整采用底部抽屉和实时预览。
- **听书**：阅读器内是紧凑控制条；离开阅读器后显示稳定高度的迷你播放器，避免布局跳动。
- **统计**：用大数字、细分割线和简洁条形图，不做彩色仪表盘或排行榜奖牌装饰。
- **书源调试**：采用清晰列表、分段状态和等宽日志。成功、警告、失败通过文字、图标和有限语义色共同表达。

## 图像素材策略

`gpt-image-2` 已检测为 Mode B：后续若原型需要真实感书封，将用宿主图像工具生成 3–5 张原创、无文字或极少文字的日系出版物封面，并保存在本项目内。v0 阶段优先使用明确标记的封面占位，避免素材先行掩盖结构问题。

## 明确避免

- 紫蓝渐变、发光、玻璃拟态、漂浮卡片堆
- 大面积米黄色单色堆叠；通过墨色、白色浮层与少量朱红建立层次
- 过多胶囊按钮、巨大圆角、装饰性插画
- 依赖颜色作为唯一状态提示
- 在阅读正文中放置功能说明、快捷键提示或宣传文案
- 预装来源不明的书源或示例正文
