# 静读 Android 原生 v0

这是已确认 Web v0 之后的 Kotlin + Jetpack Compose 原生第一阶段。原有 Web 原型仍位于 `../src/prototype/`，两者互不覆盖。

## 当前范围

- 空白初始书架、本地书籍导入，以及导入后的开始阅读 / 继续阅读入口
- 书架 / 发现 / 统计 / 我的四栏导航
- 阅读器正文、控制层、书签入口、排版面板与听书面板
- 书源 JSON 文件导入、粘贴导入、名称/地址校验与启停状态保存
- WebDAV 地址与用户名设置保存（网络同步服务尚未执行）
- 系统 TTS 朗读当前正文片段、播放/暂停与语速调节
- PDF 固定版式阅读：原生 `PdfRenderer`、可见页懒加载、48 MiB 页面缓存、适合宽度 / 显示整页两种模式与页码进度
- 本地 ZIP 备份导出与恢复（书籍文件、书源原始 JSON、阅读进度与设置）
- 恢复前完整性校验、冲突预览以及“保留本地 / 使用备份”策略
- 页面切换、控制层与底部面板的舒缓过渡动画

首次安装不内置书籍，也不生成阅读时长、完成书籍、字数或排行榜样例。统计页在尚未接入真实会话采集时保持 0；用户导入的真实书籍仍会正常保存和展示。

TXT 已支持应用私有目录复制、UTF-8/UTF-16/GB18030 编码识别、章节标题识别和正文阅读；EPUB 会安全读取应用包内的 XHTML/HTML 正文并提取标题；PDF 使用 Android 原生 `PdfRenderer` 打开应用私有文件，页面按需渲染，避免一次性解码整本文件。PDF 当前不提取文字，因此不提供 TTS；书源导入只做结构校验和本地保存，不会在导入时执行网络请求。

备份 v2 为每个文件保存大小和 SHA-256。恢复会先复制到暂存区，拒绝路径穿越、重复条目、清单不一致、内容校验失败和超限压缩包；用户确认策略后才一次性提交元数据，运行时异常会回滚已替换文件。旧版 v1 备份仍可降级恢复，但无法还原旧格式未记录的完整书籍元数据。

## 构建

本机已验证的构建入口会复用工作区中的 Android SDK、JDK 17 和 Gradle 9.3.1：

```powershell
cd C:\Users\lenovo\Desktop\workspace\project_053_android-reader\android
.\build-debug.ps1
```

APK 会复制到 `../output/quiet-reader-v0.1.0-debug.apk`。`local.properties` 是当前机器的 SDK 路径配置，换机器时请按实际 SDK 位置调整。
